# Agentic Sims

**Your Sims, with a voice of their own.** A free mod for The Sims 4 that lets you talk with your Sims
in real time, powered by [Voxta](https://voxta.ai/).

- Website: https://seeingterra.github.io/agentic-sims/
- Download: [latest release](https://github.com/seeingterra/agentic-sims/releases/latest)
- Support development: [Patreon](https://www.patreon.com/starmoose/)

> **Pre-release test build.** Agentic Sims is shared early so people can help test it before its first
> public release candidate. Things will break. Back up your saves and play on a copy, not your main save.

This repository hosts the website and the release downloads.

Agentic Sims is an unofficial fan-made mod and is not affiliated with, endorsed or sponsored by
